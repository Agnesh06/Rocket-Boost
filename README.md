# 🚀 Rocket Boost

**Precision flying · Skillful control · Clean gameplay**

> Rocket Boost is a polished Unity game where players pilot a rocket between platforms using rotation, thrust, and boost.  
> Built to showcase strong gameplay programming, physics handling, and game polish through skill-based level design.

## ⭐ Key Features

- Physics-based rocket movement with precise thrust and rotation  
- Skill-focused gameplay using gravity and force mechanics  
- Multiple levels with instant retry and smooth progression  
- Moving platforms, obstacles, and landing challenges  
- Polished experience with particle effects and audio feedback  

## 🛠 Tech Stack

- **Engine:** Unity  
- **Language:** C#  
- **Physics:** Rigidbody & Forces  
- **Input:** Unity Input System  
- **Effects:** Particle System & Lighting  
- **Audio:** AudioSource  
- **Build:** WebGL
